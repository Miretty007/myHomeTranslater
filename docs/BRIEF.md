# myHomeTranslater

Личная утилита для чтения и перевода выделенного текста на Mac. Ориентир — быстрый вызов DeepL из другого приложения.

## Сценарий

1. Выделить слово, фразу или абзац. Вызвать перевод через службу контекстного меню, горячую клавишу или включённый автоперевод.
2. Прочитать перевод у выделения, при желании скопировать. Закрыть по Esc или крестику.
3. Из строки меню открыть настройки языка перевода, темы, горячей клавиши и автоперевода.

## Устройство

Перевод выполняет Apple Translation. Языковые пакеты скачивает macOS с согласия пользователя. По умолчанию русский переводится на английский, остальные поддерживаемые языки — на русский. Можно выбрать постоянный язык. Сохраняются только настройки. Исходный текст и перевод живут в памяти до закрытия панели.

## Интерфейс

Строка меню, одна плавающая панель и окно настроек. Автоперевод выключен при первом запуске. При включении он ждёт завершения выделения и оставляет фокус в исходном приложении. Горячая клавиша по умолчанию — ⌃⌥T. Для чтения выделения из другого приложения нужно разрешение «Универсальный доступ». Служба получает текст напрямую от вызывающего приложения.
